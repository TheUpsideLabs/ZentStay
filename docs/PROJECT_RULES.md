# Golden Rules

1. Never copy another product.

Study competitors.

Understand them.

Build something better.

---

2. User First.

Every feature must solve a real user problem.

---

3. Clean Code.

Readable code is more important than clever code.

---

4. Reusability.

If code can be reused,

create a reusable component.

---

5. Mobile First.

Every screen must work perfectly on mobile before desktop.

---

6. Accessibility Matters.

Keyboard Navigation

Focus States

Color Contrast

Proper Labels

Semantic HTML

---

7. Performance Matters.

Lazy Loading

Code Splitting

Optimized Images

Server Components where applicable

Caching when needed

---

8. Security First.

Validate everything.

Never trust client data.

Protect every private API.

Use proper authentication.

---

9. Consistency.

Same spacing.

Same typography.

Same colors.

Same animations.

Same component behavior.

---

10. Documentation.

Every major feature must update

- API Reference
- Changelog
- Roadmap (if needed)
